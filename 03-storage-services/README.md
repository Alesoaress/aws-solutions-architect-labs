# 📦 Amazon S3 Storage Services

This lab demonstrates the implementation of Amazon S3 storage features, focusing on security, versioning, lifecycle management, encryption, and secure object sharing.

---

## 🎯 Objectives

- Create and configure an Amazon S3 bucket
- Enable Bucket Versioning
- Configure Server-Side Encryption (SSE-S3)
- Organize objects using folders
- Upload and manage files
- Configure Lifecycle Rules
- Generate Pre-Signed URLs
- Apply S3 security best practices
